# CMOS-Common-Source-Amplifier-LTspice
Phase-wise design and simulation of a CMOS CS amplifier with DC, AC, noise, sweeps and corner analysis.

CMOS Common-Source Amplifier Design — LTspice
This repository contains the phase-wise design and simulation of a CMOS common-source amplifier carried out in LTspice.
Key Features
DC biasing and saturation verification
AC frequency response and −3 dB bandwidth extraction
Transient analysis with phase inversion
Parameter sweeps on W, R3, and R4
Process corner and temperature analysis
Noise performance evaluation
Final Results
ID ≈ 70–75 µA
VGS ≈ 0.72 V
VDS ≈ 1.07 V
gm ≈ 0.6–0.7 mS
Gain ≈ 10 dB
fL ≈ 1.2 Hz
fH > 1 GHz
